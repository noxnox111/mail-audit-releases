# Mail Audit

Minimal static website hosted with GitHub Pages.

Website: https://noxnox111.github.io/mail-audit-releases/

GitHub Pages publishes the root directory of the `main` branch.

The landing page links to the macOS 1.1.0 test release `macos-test-20261002`. The universal DMG supports Intel and Apple Silicon. This test build is not signed with an Apple Developer ID or notarized.

The release includes the matching AGPL source archive from application commit `08ffa3c54050bc5ad2b635be72d65d6fcc4e5ac8` and SHA-256 checksums. The page uses explicit release links, so the test build does not replace the stable update feed.
