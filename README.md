# Mail Audit

Minimal static website hosted with GitHub Pages.

Website: https://noxnox111.github.io/mail-audit-releases/

GitHub Pages publishes the root directory of the `main` branch.

The landing page links to the Windows and macOS 1.2.3 test release `desktop-test-1.2.3`. The Windows installer supports x64 PCs. The universal macOS DMG supports Intel and Apple Silicon. The macOS test build is not signed with an Apple Developer ID or notarized.

The release includes the matching AGPL source archive and SHA-256 checksums. The page uses explicit release links, so the test build does not replace the stable update feed.
